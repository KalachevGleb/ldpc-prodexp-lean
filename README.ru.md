## Теорема

Пусть `C₁, …, C_m ⊆ F^n` — линейные коды. Код `C^{(i)}` состоит из слов `x : [n]^m → F`, у которых
ограничение на каждую линию направления `i` лежит в `Cᵢ`, и `C₁ ⊞ ⋯ ⊞ C_m := C^{(1)} + ⋯ + C^{(m)}`.
Для такого слова `|x|` — вес Хэмминга, `|x|ᵢ` — число линий направления `i`, на которых `x` ненулевое.
*Расширение произведения* —

```text
ρ(C₁, …, C_m) := min по x ∈ C₁ ⊞ ⋯ ⊞ C_m, x ≠ 0, величины  |x| / (n · min Σᵢ |aᵢ|ᵢ),
```

где внутренний минимум берётся по всем разложениям `x = Σᵢ aᵢ`, `aᵢ ∈ C^{(i)}`.

Двудольный граф с левыми степенями `δ` — `(α, ε)`-экспандер, если у любого множества `S` левых
вершин с `|S| ≤ α·|L|` не меньше `(1 − ε)·δ·|S|` соседей. `ExpLDPC(δ, α, ε)` — класс кодов `C = ker H`,
где `H` — матрица смежности бирегулярного `(α, ε)`-экспандера с левой степенью `δ` (левые вершины —
столбцы `H`, т.е. позиции кода).

**Теорема 1.** Для любых `m, δ ≥ 1`, `R₁, …, R_m ∈ (0, 1)`, `α > 0` и `ε ∈ [0, 1/16]` существует
`ρ₀ > 0`, зависящее только от `m`, `α` и `Δ := ⌊δ / (1 − maxᵢ Rᵢ)⌋`, такое, что `ρ(C₁, …, C_m) ≥ ρ₀`
для любой длины `n` и любых кодов `Cᵢ ∈ ExpLDPC(δ, α, ε)` длины `n` и скорости не больше `Rᵢ`.

В Lean ([`ProductExpansion/Paper.lean`](ProductExpansion/Paper.lean),
[`ProductExpansion/Main.lean`](ProductExpansion/Main.lean)):

```lean
def PaperTheoremStatement : Prop :=
  ∃ ρ : ℕ → ℕ → ℝ → ℝ, (∀ m Δ α, 0 < α → 0 < ρ m Δ α) ∧
    ∀ (F : Type) [Field F] [DecidableEq F] (m δ : ℕ) (R : Fin m → ℝ) (Rmax α ε : ℝ),
      0 < δ → (∀ i, R i ≤ Rmax) → Rmax < 1 → 0 < α → 0 ≤ ε → ε ≤ 1 / 16 →
      ∀ (n : ℕ) (C : Fin m → Submodule F (Fin n → F)),
        (∀ i, InELDPC (C i) δ α ε) → (∀ i, (Module.finrank F (C i) : ℝ) ≤ R i * n) →
        prodExpanding C (ρ m ⌊(δ : ℝ) / (1 - Rmax)⌋₊ α)

theorem paperTheorem : PaperTheoremStatement
```

Одна функция `ρ m Δ α` выражает то, что константа зависит только от `m`, `Δ` и `α`: она не зависит
от поля, длины `n`, левой степени `δ` и `ε`. Формальная формулировка немного общее текстовой: поле `F`
произвольно (конечное или нет), важен только носитель `H` (ненулевые элементы произвольны), `Rmax` —
любая общая верхняя оценка скоростей.

Теорема выводится из варианта, в котором вместо скоростей ограничены правые степени, а регулярность
графов справа не требуется ([`ProductExpansion/MainLemma.lean`](ProductExpansion/MainLemma.lean)):

```lean
def MainTheoremUniformStatement : Prop :=
  ∀ (m Δ : ℕ) (α : ℝ), 0 < α → ∃ ρ₀ : ℝ, 0 < ρ₀ ∧
    ∀ (F : Type) [Field F] [DecidableEq F] (δ : ℕ) (ε : ℝ), 0 < δ → 0 ≤ ε → ε ≤ 1 / 16 →
    ∀ (n : ℕ) (P : Fin m → Type) [∀ i, Fintype (P i)] [∀ i, DecidableEq (P i)]
      (H : ∀ i, Matrix (P i) (Fin n) F), (∀ i, IsExpanderMatrix (H i) δ Δ α ε) →
      prodExpanding (fun i => kerCode (H i)) ρ₀

theorem mainTheoremUniform : MainTheoremUniformStatement
```

## Что нужно проверить читателю

Доказательства проверяет Lean. Чтобы доверять результату, достаточно убедиться, что определения
в формулировках означают то же, что в тезисах. Это около 200 строк:
[`Basic.lean`](ProductExpansion/Basic.lean), определения `IsBiregular`, `InELDPC` и
`PaperTheoremStatement` в [`Paper.lean`](ProductExpansion/Paper.lean) и
`MainTheoremUniformStatement` в [`MainLemma.lean`](ProductExpansion/MainLemma.lean).

| Тезисы | Lean |
| --- | --- |
| поле `F_q` | любое поле `F` |
| слово на кубе `[n]^m` | `(ι → Fin n) → F`, в теореме `ι = Fin m` |
| линия направления `i` через `y`, ограничение `x\|_ℓ` | `line i y`, `restrictLine x i y` |
| `C^{(i)}` | `colCode C i` |
| `C₁ ⊞ ⋯ ⊞ C_m` | `boxplus C` |
| `\|x\|`, `\|x\|ᵢ` | `weight x`, `lineWeight x i _` |
| `ρ(C₁, …, C_m) ≥ ρ₀` | `prodExpanding C ρ₀` |
| окрестность `N(S)` в графе Таннера `H` | `nbhd H S` |
| `ker H` | `kerCode H` |
| `(α, ε)`-экспандер с левой степенью `δ` и правыми `≤ Δ` | `IsExpanderMatrix H δ Δ α ε` |
| `C ∈ ExpLDPC(δ, α, ε)` | `InELDPC C δ α ε` |
| скорость `C` не больше `R` | `Module.finrank F C ≤ R * n` |

`prodExpanding C ρ₀` означает, что у каждого `x ∈ C₁ ⊞ ⋯ ⊞ C_m` есть разложение `x = Σᵢ aᵢ`,
`aᵢ ∈ C^{(i)}`, с `ρ₀ · n · Σᵢ |aᵢ|ᵢ ≤ |x|`; это равносильно `ρ(C₁, …, C_m) ≥ ρ₀`.

Файл [`Verify.lean`](Verify.lean) проверяет, что теоремы используют только стандартные аксиомы
`propext`, `Classical.choice` и `Quot.sound`; в частности, `sorry` нет.

## Сборка

Установите Lean через [elan](https://github.com/leanprover/elan) (версия задана в `lean-toolchain`:
Lean 4.34.1, Mathlib v4.34.1), затем

```sh
git clone https://github.com/KalachevGleb/ldpc-prodexp-lean.git
cd ldpc-prodexp-lean
lake exe cache get        # готовые .olean Mathlib
lake build                # проверка всех доказательств
lake env lean Verify.lean # проверка аксиом; при успехе ничего не выводит
```

После загрузки кэша Mathlib `lake build` занимает около 3 минут.

Те же шаги выполняются в GitHub Actions при каждом push
([`.github/workflows/lean_action_ci.yml`](.github/workflows/lean_action_ci.yml)).

## Устройство доказательства

| Модуль | Содержание |
| --- | --- |
| `Basic` | Куб, линии, `C^{(i)}`, `⊞`, веса, расширение произведения, матрицы-экспандеры. |
| `Expander` | Уникальные соседи, расстояние `> αn`, жадное замыкание `F_θ` (леммы `gen-unique`, `gen-find`). |
| `Cube`, `CubeLemmas` | Грани, базы `B_I`, множества `Y_I`, замкнутые множества и их свойства (F1)–(F3), `L(M)`. |
| `Closure`, `Reduction` | Малые замкнутые надмножества (`gen-closure`), сведение расширения произведения к `P(m)` (`gen-reduction`), случай `αn < 2`. |
| `Syndrome`, `FaceSyn` | Синдромное условие `S(E)` (`def:syn`), лемма о синдроме грани (`face-syn`). |
| `Canonical` | Канонические множества ошибок (`def:can`), лемма `CL`, хорошие линии (`good`). |
| `MainInterface`, `Step2` … `Step5` | Формулировки и доказательства шагов 2–5 леммы `D(d)`. |
| `MainLemma` | Константы `κ_d`, лемма `D(d)` индукцией, следствие `P(d)`, теорема 1 для наборов матриц-экспандеров. |
| `Paper`, `Main` | Оценка правых степеней через скорость; итоговые теоремы. |

Комментарии в коде ссылаются на утверждения доказательства по коротким меткам:

| Метка | Утверждение |
| --- | --- |
| `gen-unique` | Если `\|S\| ≤ αn`, то у `S` не меньше `(1 − 2ε)δ\|S\|` уникальных соседей; расстояние `ker H` больше `αn`. |
| `gen-find` | Оценки жадного замыкания `F_θ(R)`: его мощность и `supp e ⊆ F_h(R)` при `supp(He) ⊆ R`, `h = (1 − 2ε)δ`. |
| `gen-closure` | Наименьшее `η`-замкнутое надмножество `S ⊆ [n]^m` имеет мощность не больше `((2^m + 1)/η)^m \|S\|` (Калачев–Пантелеев, FOCS 2025, лемма 18). |
| `gen-reduction` | Если верно `P(m)` с порогом `η`, то `ρ(C₁, …, C_m) ≥ 1/(m·c_{m,η})`. |
| `P(d)` | Всякое собственное `η`-замкнутое множество `M ⊆ [n]^d`, `η ≤ η_d`, порождается изнутри: каждое слово `C₁ ⊞ ⋯ ⊞ C_d` с носителем в `M` есть сумма кодовых слов на линиях, лежащих в `M`. |
| `def:syn` | Синдромное условие `S_d(E)` с дефектом `E`. |
| `face-syn` | Ограничение слова, удовлетворяющего `S_d(E)`, на грань удовлетворяет синдромному условию с явно заданным дефектом. |
| `def:can` | Канонические множества ошибок `Bad_J`, `Can(Y)`, `Ŷ`. |
| `CL` | Замкнутость и согласованность канонических множеств. |
| `good` | Существование хорошей линии и её свойства (G1)–(G4). |
| `D(d)` | Декодирование с дефектом, основная лемма; доказывается индукцией по `d` в пять шагов. |

Без ограничения общности в доказательстве `α ≤ 1` и `ε = 1/16`, так как свойство расширения монотонно по этим параметрам.
